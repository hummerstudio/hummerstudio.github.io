## 1. Download the public security icon

Save it as `gongan.png`

## 2. Upload it to the server

Location: `/var/www/html/static/common/gongan.png`


## 3. Modify the code

File to modify: `/var/www/html/views/default/global/footer.tpl.htm`, insert it at the desired position.

One part of the code generated by the filing website is:

```
<img src="" style="float:left;"/>
```
Fill in the icon path at `src`:

```
<img src="static/common/gongan.png" style="float:left;"/>
```

## 4. Style tuning

The first line of code is:

```
<div style="width:300px;margin:0 auto; padding:20px 0;">
```

Filing information is usually placed at the bottom of the site, and the default style leaves too much vertical spacing, which looks unattractive. You can delete `padding:20px 0;`.

## 5. Hiding it on small screens

When you visit the site on a small screen, you'll find the filing information at the bottom looks jarring. Looking at the mobile version of Tencent (腾讯网), you'll see that it does not display this kind of information on mobile.

We can hide it as well.

Just add `class = "hidden-xs"` to the first `div`.

### 6. Note

Changes take effect in real time; there is no need to reload the configuration or restart the service process.
