#### .NET Runtime
Contains only the components needed to run console apps. You need to install the ASP.NET Core Runtime and the .NET Desktop Runtime separately.

#### ASP.NET Core Runtime
Runs web/server apps. On Windows, installing the **Hosting Bundle** is recommended; it includes the .NET Runtime and IIS support.

#### .NET Desktop Runtime
Runs Windows desktop apps. It includes the .NET Runtime, so there is no need to install it separately.
