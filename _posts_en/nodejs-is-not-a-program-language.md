Strictly speaking, `Node.js` is not a programming language but a runtime, similar to the `JVM`.

`Java` runs on the `JVM`, and `Javascript` runs on `Node.js`.

In a word, `Node.js` is a `JavaScript` runtime environment built on the Chrome V8 engine.
