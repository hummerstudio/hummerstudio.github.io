## Introducing Octicons

Octicons is an extensible icon set produced officially by GitHub, and it is an open-source project.

Octicons contains a set of icons in SVG format, built by Github and used by Github.

Of course, because it is an open-source project, other products can use it too. The official project has also specifically added support for `nodejs`, `react`, `ruby`, `rails` and `jekyll`.

Octicons icons are used in several places in this blog's theme, such as the icons for article categories and the icons for article tags; in particular, the icon in front of every menu item in the menu bar is an Octicons icon.
